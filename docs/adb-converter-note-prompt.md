# 給 adb-converter 的提示詞：閱讀器支援 `n="章.註@冊"`

> 2026-11-02。ys.adb 的 `<註>`／`<釋>` 已改成 `章.註@冊`；這份是給
> `D:\2026\adb-converter` 工作區改 accelon26 閱讀器用的提示詞，可直接整段貼。

```text
【任務】accelon26 閱讀器支援新的註號語法 `n="章.註@冊"`

■ 背景
ys.adb（印順法師全集）的 `<註 n="…"/>` 與 `<釋 n="…">` 改成：
    <註 n="11.001@38"/>
    <釋 n="11.001@38">…</釋>
`@` 前面是紙本註號（章.註），`@` 後面是冊號，只用來保證全 adb 唯一。
舊 adb 仍是 `n="38.160"`（沒有 `@`），要向下相容。

■ 要改的地方
1. 新增一個顯示用的 helper，例如：
     export const noteLabel = (n: string): string => {
       const at = n.indexOf('@');
       return at >= 0 ? n.slice(0, at) : n;
     };
   放在合適的共用模組（例如 src/accelon26/notes.ts 或現有的 util）。
2. 所有「顯示註號」的地方改用 noteLabel()：
   - 正文的 <註> 標記（chip／上標）
   - <釋> 標題、釋文清單、註釋分頁
   - hover／tooltip、複製、匯出、無障礙標籤
   - 任何 `「註 ${n}」` 之類的字串
3. 所有「查表／比對」的地方仍用完整 n（含 @冊）：
   - <註> → <釋> 的對應、跳轉、反查、xrev、書籤
   - 不要用 noteLabel 去當 key，否則跨冊會撞號
4. 若 UI 有「跳到註」或「註 N」輸入框，接受 `11.001` 或 `11.001@38` 兩種；
   只有章.註時，在目前這本書內找（書內唯一），找不到再提示需要冊號。
5. 樣式不用改；`@` 不應出現在畫面上。

■ 驗收
- 開 D:\accelon3\ys.adb，38p0081a 附近應顯示「11.001」，不是「11.001@38」。
- 點 <註> 仍能找到對應 <釋>（用完整 key），釋文標題顯示 11.001。
- 舊 adb（沒有 @）行為完全不變。
- 加一個單元測試：noteLabel('11.001@38')==='11.001'、noteLabel('38.160')==='38.160'。
- 既有的 render／reader 測試要全過。

■ 注意
- 只改顯示與比對，不要改 adb 格式。
- 不要動 ys 工作區；ys.adb 由 ys repo 產生。
```
